# Поиск и единица ответа

Разбор 24.10.2026: по каждому семейству — кто им пользуется, какие вопросы задаёт, что для него «ответ».
Шли от специальностей, не от возможностей базы. Полные разборы (роли, 34–39 вопросов на семейство, большинство
сверено с текстами, требования к поиску) — в `вопросы/`, там же образец промта санитарного агента как пример
ожиданий. Эти вопросы — заготовка эталона качества.

## Общее для всех семейств

**Единица ответа одна и та же: структурная единица документа в редакции на дату.** Её виды встречаются во всех
семействах, различается только частота:

| Вид | Где главный | Что обязательно в комплекте |
|---|---|---|
| пункт / подпункт / абзац (у законов и ТР — статья → часть → пункт) | все | путь с названиями раздела и статьи, адрес до абзаца — абзац часто несёт исключение |
| строка таблицы | санитарные нормативы, СП, ТР, приложения ПП | шапка столбцов с единицами, группа строк, все величины строки, все сноски, пункты-примечания вне таблицы; ячейка — не единица выдачи |
| карточка документа | стандарты (половина вопросов), везде для «действует ли, чем заменён, какая редакция» | статус с датой, замены, редакции, срок действия |
| приложение-форма | охрана труда, ЦБ, ПП | обязательная форма или рекомендуемый образец |
| сводка из нескольких фрагментов | все (порог зависит от условий: ветер — 5 порогов по видам работ; журнал — из 8 мест) | — |
| пара редакций одного фрагмента («что изменилось», «что действовало на дату») | все | даты, изменяющий акт |
| отсылка как ответ («определяет изготовитель», «по СП 309», «устанавливается Правительством») | все | адрес цели, если разрешена; честное «не разрешена» |

**Время — не свойство документа, а измерение запроса.** Везде спрашивают «на дату», «что изменилось», «что будет».
Редакция и статус нужны на уровне пункта: интервал действия формулировки, изменяющий акт, отложенное применение,
подписанные и не вступившие изменения. Статус «истёк срок» отличать от «отменён»: у ПОТ, ППР, СП срок встроен
в акт (782н истёк 31.12.2025, ППРФ 1479 — до 31.12.2026, замен на источниках нет).

**Поиск — пять входов, одинаковых у всех семейств:**

1. по объекту и ситуации на бытовом языке — нужен словарь «бытовое → термин документа», словари семейные;
2. по числовому параметру с условиями — значение, единица, квалификатор (не менее / не более / диапазон), период;
3. по обозначению и реквизитам — нормализация (с годом и без, жаргон, опечатки, суффиксы), без года → действующая редакция;
4. по дате, редакции, статусу;
5. по связи — закон → подзаконный акт, норматив → методика, ТР → перечень → ГОСТ, ППР ↔ СП МЧС.

Плюс фильтры по атрибутам фрагмента: адресат (кому обязанность), объект (тип здания, вид организации, группа
продукции, среда), роль. Механизм общий, наборы атрибутов и словари — семейные.

**Стык семейств — штатный режим, не исключение.** Почти каждый вопрос тянет 2–4 семейства: СанПиН + 52-ФЗ + ПП;
ПОТ + ПП 2464 + ТК; СП + 123-ФЗ + ППРФ 1479 + СанПиН; ТР + ГОСТ + СанПиН; ЦБ + ФЗ + ГОСТ 57580. Следствия:
агрегатор маршрутизирует по области в несколько семейств сразу; ограничение «вне санитарного — нормы нет»
в образце промта слишком узкое; нужна связь «назвать смежный документ, если пришёл из другого семейства».

**Границы одинаковы везде:** база даёт норму, редакцию, статус и связи; не квалифицирует («нарушение ли это»),
не считает ответственность, не выбирает между расходящимися нормами, не делает расчёты (рассеивание, эвакуация,
риск), не относит товар к ТР или коду ТН ВЭД, не цитирует письма и разъяснения ведомств (не НПА), не отвечает по памяти.

**Чего не покрывает образец промта** (по санитарному разбору, применимо ко всем): выбор среды/объекта, когда он не
назван; синонимы (CAS); пункты-примечания вне таблицы; ответ «на дату» и соответствие старых и новых пунктов;
ответ уровня документа («какие документы нужны для кафе»); разделение норма / методика / рекомендация;
применимость (проектирование или эксплуатация); неоднозначные номера таблиц в подписи (две «Таблица 5.25» в СанПиН 1.2.3685-21);
оговорка для текста из сканов; смежные семейства.

## Семейное

| Семейство | Единица ответа чаще всего | Свои атрибуты и словари | Особенности |
|---|---|---|---|
| законы | часть/пункт статьи с названием статьи | делегирование (кому, каким актом), будущие редакции, пометки портала (КС, особенности применения) | сносок нет; части в ТК не нумерованы; надстрочные номера статей (5¹ vs 51) — адреса только из разметки портала; связь «статья → подзаконный акт» строится от подзаконных актов |
| санитарные правила | подпункт; строка таблицы | среда/фактор, вещество + CAS + синонимы, несколько величин в строке, класс опасности, таблица соответствия пунктов при замене | 4 разные ПДК формальдегида по средам; поправки к норме отдельными пунктами; МУ/МУК/МР — то же семейство, но методики, не нормы (признак необязательности, подключать по «как измерить»); связь норматив → методика есть только в МУК |
| охрана труда | пункт с абзацами; форма; карточка нормы СИЗ | роли и группы работников, вид работ = раздел, делегировано изготовителю/работодателю, статус формы | один параметр с порогами по видам работ; больше половины ссылок внутрь документа, бывают ошибочные; нормы СИЗ — 5357 профессий, точный поиск по названию |
| акты Правительства | пункт утверждённых Правил; строка приложения; карточка обёртки | адресат, объект, периодичность, порождаемые документы (журнал, акт), применение пункта с даты из обёртки | консолидация готова (actual); редакций много; содержание разнородно (пожарные правила, обучение по ОТ, лицензирование) — **тег области обязателен**; ППРФ 1479 стоит в `федерация.md` в строке МЧС, а дом — акты Правительства |
| своды правил | пункт в редакции; строка таблицы с условиями | статус требования на дату (ПП 815 утратило силу с 01.09.2024 → реестр требований Минстроя по ПП 1417/2023; пожарные СП добровольны по 123-ФЗ), цепочка замен до СНиП, изменения как документы, дубли с другим ведомством | параметры объекта (площадь, этажность, класс Ф) — фильтр по диапазонам, не текст; маршрутизация «тип здания → профильный СП» по табл. Б.1 СП 118; рисунки и формулы в тексте теряются |
| стандарты | карточка (≈ 50 % вопросов), потом пункт/таблица/термин | вид (межгос./нац./ПНСТ), статус с датой и территорией («утратил силу в РФ»), три вида замен и частичность, ОКС, доступность текста, перечни к ТР | без текстов каталог полезен и нужен другим семействам для разрешения ссылок; обозначение без года → действующая редакция и переход ГОСТ → ГОСТ Р; цепочки замен многошаговые с обрывами |
| акты Банка России | подпункт глубокой нумерации в собранной нами редакции | адресат-организация, этап жизни (Минюст), вступление по частям с расчётной датой, история пункта, раскрытие «далее —» | номер без суффикса (-П/-У/-И) неоднозначен; на cbr.ru только исходная редакция и нет связи с изменяющими указаниями — реестр изменений собирается из сносок новых актов; три вида поломки OCR |
| ТР ЕАЭС | часть/пункт статьи; строка таблицы приложения | группа продукции и исключения, форма и схема оценки соответствия, переходные периоды, связанные ТР и перечни, ТН ВЭД из перечней | на товар несколько ТР; граф связей не из текста, а из карточки ТР и перечней; редакцию на дату собираем сами; русский текст официальный |

## Что следует для общей библиотеки

- Модель результата общая: вид единицы, адрес с путём, текст, значения с условиями и сносками, статус и редакция
  на уровне пункта, связи. Семейные атрибуты — расширение, не другая модель.
- Поиск — общий механизм по пяти входам с атрибутными фильтрами; словари и экстракторы атрибутов — семейные.
- Каталог (документы, статусы, замены, редакции, разрешение обозначений) нужен всем и один; статус пункта/требования
  поверх него — у СП и ПП.
- Консолидация: у законов, указов и ПП готовая (actual); у остальных пяти семейств — наша, из инструкций «изложить
  в редакции», с признаком «собрано нами» и сверкой. Адаптер actual — первый кандидат в библиотеку (три семейства,
  одна разметка, стабильные id абзацев, сравнение редакций по id).
- Семейств не хватает: Минздрав (медосмотры), ФСТЭК и ФСБ (вместе с ЦБ), Минприроды, реестры (ФСА) — пока
  «в базе такой нормы нет».

## Технические находки по источникам

- ИПС: большие документы целиком только с `&fulltext=1` (иначе 767н обрезан на букве «А» и выглядит целым);
  СанПиН 1.2.3685-21 скачался только печатной формой `?docview&page=all&print=1` с Referer на `docbody`;
  частые ответы 204 с пустым телом — повтор через 30 с.
- actual: вставленные пункты с надстрочными номерами при наивном разборе склеиваются («2¹» → «21»); флаг «текст не
  готов» ложный; id абзацев стабильны между редакциями (между 2024 и 2025 в 1479 изменилось 64 абзаца).
- Сканы Роспотребнадзора: номер и дата МУ/МР вписаны от руки, OCR их не читает — реквизиты только из метаданных публикации.
- eaeunion.org: в XML API статусы пустые, связей изменений нет; в DOCX потеряны надстрочные номера, в PDF отрываются степени.
- Образцы на ВМ: `~/src/q/<семейство>/` — скачанные агентами тексты (21 закон, ПП 2464 и 1128, СанПиН 1.2.3685-21, 767н, 384-ФЗ, 123-ФЗ).
