# Регуляторка

Нормативные знания для людей и ИИ.

## Что это

Онлайн-база нормативных документов РФ с доступом через MCP. Главный потребитель — ИИ-агент, которому нужен точный пункт, а не список ссылок. Наполняется пакетами по семействам документов; догонять справочные системы («Техэксперт») по числу документов и функций цели нет.

Что даёт ИИ, чего нет у справочных систем:
- норматив как структурированные данные с адресом и статусом;
- ответ с точным пунктом и датой актуальности;
- действующая замена для отменённого акта;
- вопрос на стыке нескольких областей одним запросом.

## Принципы

1. **Каждый фрагмент адресован.** Документ, раздел, пункт, таблица. Ответ без адреса — дефект.
2. **Только официальные источники.** Тексты из официального опубликования. Консолидацию изменений делаем сами и фиксируем в реестре. Из коммерческих правовых систем не копируем.
3. **Статус документа — часть данных.** Отменённые и изменённые помечены, поиск по умолчанию отдаёт только действующие, связь «заменён на» хранится в реестре.
4. **Качество измеряется.** Эталонный набор вопросов и метрики; без прогона не выкатываем.
5. **Запросы клиентов обрабатываются в России.** Эмбеддинг запроса, реранк и генерация — только модели на территории РФ; для части клиентов — только суверенные (YandexGPT, GigaChat). Обработка самих документов (парсинг, консолидация, эталон) — публичные данные, модели любые.
