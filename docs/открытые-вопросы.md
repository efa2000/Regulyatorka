# Открытые вопросы

Только нерешённое. Решили — удаляем отсюда, решение попадает в соответствующий документ.


- **Обязательность пунктов строительных СП.** ПП 815 утратило силу с 01.09.2024; по 384-ФЗ ст. 6 требование применяется со дня включения в реестр требований Минстроя («Стройкомплекс.РФ», ПП 1417/2023). Официальный ли это для нас источник, есть ли выгрузка и детализация по пунктам — не разведано. Статус пункта нужен на дату: до 01.09.2024 по ПП 815, после — по реестру.
- **Замены истекающих актов.** 782н (работы на высоте) истёк 31.12.2025, ППРФ 1479 действует до 31.12.2026 — преемников на официальных источниках не найдено. Как отвечать по истёкшему акту без замены.
- **Недостающие семейства.** Вопросы штатно требуют акты Минздрава (медосмотры), ФСТЭК и ФСБ (вместе с ЦБ), Минприроды, реестры ФСА (действует ли декларация). Подключать ли и когда.
- **МУ, МУК, МР в семействе санитарных правил.** Тот же издатель и источник, но методики, а не нормы. Предложение: признак необязательности, подключать по запросам «как измерить» и по связи норматив → методика.
- **Тексты ГОСТ.** Легальный путь получения полных текстов и реестра protect.gost.ru (соглашение сайта запрещает автоматический сбор) — прорабатывается.
