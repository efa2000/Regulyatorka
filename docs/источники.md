# Источники документов

## Политика

Берём тексты только из официальных источников — тех, где документ по закону официально публикуется или
официально распространяется. Копии на сайтах ведомств, у подведомственных учреждений и экспорт из
коммерческих правовых систем не используем, даже если они удобнее. Чего в официальных источниках нет —
ищем руками. Если с официальным источником работать невозможно (как сейчас с текстами ГОСТ) — отдельное
решение, не обход через копии.

Все источники ниже доступны только с российского IP — работаем с ВМ `regulyatorka-fetch`
(`docs/инфраструктура.md`). Образцы и скрипты разведки 23.10.2026 — на ВМ в `~/src/`, тексты норм — в `~/src/law`.

## pravo.gov.ru — три сервиса одного источника

Указ № 90 от 03.03.2022: портал — «единый официальный государственный информационно-правовой ресурс»,
а **тексты актов с внесёнными изменениями, размещаемые на портале с 01.07.2022, являются официальными**.
Для законов и актов Президента/Правительства официальны также электронные тексты НТЦ «Система» ФСО
(Указ № 662 п. 2, Указ № 763 п. 2).

- **publication.pravo.gov.ru — официальное опубликование.** От него считается вступление в силу. Только
  сканы PDF без текстового слоя (включая документы 2026 г.). JSON API `/api/Documents`,
  `/api/Document?eoNumber=` — издатель с устойчивым id, тип (47 видов), дата, номер, регистрация в Минюсте.
  Роль: `source_url`, мониторинг новых публикаций, OCR для свежих документов, которых ещё нет в текстовых сервисах.
- **actual.pravo.gov.ru — актуальные тексты.** JSON API `:8000/api/ebpi/` без авторизации, 277 тыс. актов:
  законы, указы, постановления Правительства; ведомственных актов нет. Консолидированные редакции с
  датами вступления в силу (включая будущие), текст HTML со стабильными id абзацев, оглавление до пункта
  (`getcontent`). Основной источник для законов, указов, актов Правительства.
- **ИПС «Законодательство России»** (`pravo.gov.ru/proxy/ips/`) — эталонный банк. Единственный текстовый
  источник ведомственных актов: СП 2.4.3648-20, приказ 782н, приказы МЧС есть текстом. HTML из Word без
  якорей, пункты не размечены, верхние индексы теряются, таблицы `<table>`, cp1251, медленно, поиск —
  полной формой. Редакции отстают на месяцы, статусам доверять нельзя (782н «действует без изменений»
  при истёкшем сроке).

## Что следует из разведки для всех семейств

- **Консолидацию ведомственных актов, сводов правил, актов ЦБ и ЕАЭС делаем сами**: официальные
  источники публикуют изменения отдельными документами в виде инструкций «пункт N изложить в редакции».
  Для законов, указов и актов Правительства консолидация уже есть на actual.pravo.gov.ru.
- **Реестр статусов ведём сами**: статус выводится из отмен, замен и сроков действия в самих актах
  (СП 2.4.3648-20 утратил силу с 01.09.2026 — заменён СП 2.4.2.4283-26; ППРФ 1479 — до 31.12.2026;
  приказ 782н — до 31.12.2025).
- **Единица хранения — утверждаемый документ**, акт-обёртка — источник метаданных.
- **Входные форматы**: HTML из Word (ИПС, actual), PDF с текстом и DOCX (ЕАЭС), скан (publication, cbr.ru,
  protect). Набор элементов структуры везде один: раздел → пункт → подпункт → абзац, таблицы, приложения;
  схемы нумерации разные (`2.4.6.1`; римские разделы со сквозными пунктами; статья/часть; `5.1` и приложение Б).
