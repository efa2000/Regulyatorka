Описание проекта Regulyatorka

## 1. Что это

**Регуляторка** — «Нормативные знания для людей и ИИ» (имя продукта и слоган приняты 20.10.2026; SanPinBase — прежнее имя, сохранено как имя репозитория и технических идентификаторов). 


Ориентир из «прошлого мира» — профессиональные справочные системы вроде «Техэксперта»: инсталляция у клиента, ручной поиск, продажа по разделам и рабочим местам. Регуляторка делает иначе: онлайн-база, доступная отовсюду, с доступом для ИИ через MCP; наполнение «крупными мазками» по пакетам без цели догнать справочные системы по числу документов и функций. Отличия, которые важны именно для ИИ: нормативы как структурированные данные с адресом и статусом, ответ с точным пунктом и датой актуальности, действующая замена для отменённого акта, межблочные вопросы одним запросом. 

**Каждый фрагмент адресован.** Любой ответ опирается на фрагмент с адресом: документ, раздел, пункт, таблица. Ответ без адреса считается дефектом.
**Только официальные источники.** Тексты берутся из официального опубликования. Консолидация изменений делается нами и фиксируется в реестре. Тексты из коммерческих правовых систем не копируются.
**Статус документа — часть данных.** Отменённые и изменённые документы помечены, поиск по умолчанию отдаёт только действующие, связь «заменён на» хранится в реестре.
**Качество измеряется.** Эталонный набор вопросов и метрики прогоняются .
**Запросы клиентов обрабатываются в России** Эмбеддинг запроса, реранк и генерация ответа в наших продуктах — только моделями, размещёнными на территории РФ; для части клиентов — только суверенными (YandexGPT, GigaChat). Обработка самих документов (парсинг, консолидация, эталон) — публичные данные, для неё допустимы любые модели.
