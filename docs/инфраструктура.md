# Инфраструктура

**Хостинг — Cloud.ru, платформа Evolution.** Решение от 23.10.2026.

Управление облаком из Claude Code — через публичный API Cloud.ru без сторонних SDK: навык
`.claude/skills/cloudru` (обёртка над curl с кэшем токена и чтение официальных OpenAPI-спек).
Учётные данные сервисного аккаунта хранятся вне репозитория в `~/.config/cloudru/credentials`;
что создать в консоли — `.claude/skills/cloudru/references/console-setup.md`.

Официального MCP у Cloud.ru нет (на 23.10.2026); Terraform-провайдер Cloud.ru есть, пока не используем.

## ВМ для загрузки источников

`regulyatorka-fetch` — Debian 12 в Cloud.ru (ru.AZ-1, флейвор `lowcost10-1-2`: 1 vCPU, 2 ГБ, HDD 20 ГБ),
публичный IP `176.109.109.144`, доступ `ssh regulyatorka-fetch` (ключ `~/.ssh/regulyatorka_ed25519`,
пользователь `efa`, группа безопасности — только 22/tcp). Создана 23.10.2026.

Зачем: pravo.gov.ru (ИПС), fgis.gost.ru, rospotrebnadzor.ru и ряд других госсайтов не отвечают с зарубежных
IP, а рабочая машина `efa` стоит в Швеции. Всё, что ходит к источникам, запускаем отсюда. Установлены
curl, poppler-utils, tesseract (rus), jq, python3. Образцы документов — в `~/src/`.

## Домен

`regulyatorka.ru` — регистрация в Timeweb, DNS-зона в Cloud.ru (`regulyatorka-ru`), NS
`evo-cns01.cloud.ru`, `evo-cns02.cloud.ru`. MX, SPF, DKIM и DMARC пока указывают на почту Timeweb.

## LLM-прокси к зарубежным моделям

Зарубежные модели из РФ недоступны, поэтому к ним ходим через прокси за рубежом. Прокси — только для
зарубежных моделей; российские (YandexGPT, GigaChat и др.) подключаем напрямую, не через него.

- Сервер `130.17.16.182` (Fornex, Швеция, Debian 12, 1 vCPU / 1 ГБ + 2 ГБ swap). SSH только по ключу,
  пользователь `efa`, root по SSH закрыт; ufw (22, 80, 443), fail2ban, автообновления безопасности.
  Доступ: `ssh llm-proxy` (ключ `~/.ssh/llmproxy_ed25519`).
- **LiteLLM Proxy** (единый OpenAI-совместимый API к любым провайдерам) + Caddy (HTTPS, сертификат
  автоматически) в Docker Compose, `/opt/litellm`. Образы закреплены по дайджесту. Без БД.
- Адрес `https://llm.regulyatorka.ru`, авторизация `Authorization: Bearer <master key>`. Мастер-ключ
  на сервере в `/opt/litellm/.env`, локально в `~/.config/llm-proxy/credentials`.
- OpenAI подключён шаблоном: любая модель вызывается как `openai/<модель>` (например `openai/gpt-5.4-mini`).
- Новый провайдер: ключ в `.env`, шаблон или модель в `config.yaml`, затем `docker compose up -d --force-recreate litellm`.
