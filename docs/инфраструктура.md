# Инфраструктура

**Хостинг — Cloud.ru, платформа Evolution.** Решение от 23.10.2026.

Управление облаком из Claude Code — через публичный API Cloud.ru без сторонних SDK: навык
`.claude/skills/cloudru` (обёртка над curl с кэшем токена и чтение официальных OpenAPI-спек).
Учётные данные сервисного аккаунта хранятся вне репозитория в `~/.config/cloudru/credentials`;
что создать в консоли — `.claude/skills/cloudru/references/console-setup.md`.

Официального MCP у Cloud.ru нет (на 23.10.2026); Terraform-провайдер Cloud.ru есть, пока не используем.
